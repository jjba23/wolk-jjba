** A new deployment

After installing Guix system on the VPS, we should reboot into the installation.

Then proceed to do a ~guix pull~ to update to the latest channels and Guix version.

Then, since I manage my VPS configuration from [[https://codeberg.org/jjba23/byggsteg][byggsteg]], I will create the needed dir, as root:

#+begin_example
# mkdir -p /etc/byggsteg/job-clone/wolk-jjba
# cd /etc/byggsteg/job-clone/wolk-jjba
# guix shell git make
# git clone https://codeberg.org/jjba23/wolk-jjba trunk
# exit

#+end_example

Then we can reconfigure the system *as our normal user*!
#+begin_example
$ cd /etc/byggsteg/job-clone/wolk-jjba/trunk
$ guix shell git make
$ make sr
#+end_example


After it's all complete, I reboot the machine and then configure Guix home for ~joe~

#+begin_example
$ make jr
#+end_example

Then install byggsteg and start some projects, all as root:
#+begin_example
# mkdir -p /etc/byggsteg/job-clone/byggsteg
# cd /etc/byggsteg/job-clone/byggsteg
# git clone https://codeberg.org/jjba23/byggsteg
#+end_example


Then download some backups to the dirs:

#+begin_example
$ make fetch-backup-byggsteg-db
#+end_example

It can be nice to disable in the ~config.scm~ the Nginx and Certbot services in the beginning.

#+begin_example
         ;;(wolk-jjba-nginx #:minimal-conf #t)
         ;;wolk-jjba-certbot
#+end_example


Then activate firstly a minimal nginx to make the certs:

#+begin_example
         (wolk-jjba-nginx #:minimal-conf #t)
         wolk-jjba-certbot
#+end_example

Then activate all services nginx:

#+begin_example
         (wolk-jjba-nginx #:minimal-conf #f)
         wolk-jjba-certbot
#+end_example
